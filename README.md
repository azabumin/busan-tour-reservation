# 釜山旅行デスク / 부산 관광 예약·스케줄 관리

일본인 관광객을 대상으로 한 **부산 여행 예약 접수 + 예약 현황 파악 + 일정 정리** 앱입니다.
빌드·설치 없이 `index.html` 하나로 동작합니다.

🔗 **https://azabumin.github.io/busan-tour-reservation/**

## 기능

| 탭 | 내용 |
|---|---|
| 予約フォーム | 코스(1일 / 2박3일 / 3박4일) → 달력에서 출발일 → 목적(쇼핑·맛집·명소·기타)과 구체적 희망 → 예약자 정보(전화·메일·LINE ID·동행자 수) → **제안 일정 확인·수정** |
| 予約状況 | 통계, 검색·필터, 상태 변경(仮予約/確定/キャンセル), 담당 메모, CSV 출력, 행정표 인쇄 |
| スケジュール | 월 달력에 예약 표시, 날짜별 그날의 행정 확인 |

### 제안 일정 (스케줄案)

고객이 적은 자유 문장을 키워드로 읽어 부산의 실제 스팟에서 일정을 자동으로 짭니다.

- 「海鮮・刺身」 → 자갈치시장, 민락 회센터 등을 식사에 우선 배치
- 「辛い料理が苦手」 → 매운 집 감점, 순한 음식 우선
- 「歩く距離を短めに」 → 하루 일정 수를 줄이고 같은 지역으로 묶음
- 같은 장소 중복 금지 / 지역 4권역 + 이동시간 반영 / 야간 전용 스팟은 낮에 배치하지 않음

고객은 제안된 일정을 보고 시간 변경·다른 후보로 교체·삭제·추가(자유 입력 포함)를 한 뒤 예약을 확정합니다.

## 제약

- 예약 데이터는 **브라우저의 localStorage**에만 저장됩니다. 기기·브라우저가 다르면 서로 보이지 않습니다.
- 여러 기기에서 같은 목록을 공유하려면 서버(DB) 연결이 필요합니다.
- 메일/LINE 자동 발송 기능은 없습니다.
