# 写真フォルダ / 사진 폴더

이 폴더에 **JPG 파일을 넣기만 하면**, 일정표의 일러스트가 그 사진으로 자동으로 바뀝니다.
코드는 고치지 않아도 됩니다. (파일이 없으면 내장 일러스트가 그대로 표시됩니다.)

- 파일명은 아래 표의 이름 그대로, 확장자는 `.jpg`
- 권장 크기: 가로 640px 내외, 가로:세로 = 4:3 (예: 640×480)
- 저작권: **직접 촬영한 사진이나 사용 허락을 받은 사진만** 넣어 주세요.

## 특정 가게의 사진만 따로 쓰고 싶을 때

`index.html` 안 `var SPOTS = {...}` 에서 해당 스팟에 `photo` 를 추가하면 그 사진이 우선됩니다.

```js
{n:'チャガルチ市場（2階の食堂で活魚料理）', pic:'sashimi', photo:'images/jagalchi-2f.jpg', a:'W', ...}
```

## 참고

- 사진을 넣기 전에는 브라우저 개발자 콘솔에 `images/xxx.jpg 404` 메시지가 나옵니다.
  사진이 없다는 확인일 뿐이라 앱 동작에는 지장이 없으며, 화면에는 일러스트가 정상적으로 표시됩니다.
- 사진을 넣거나 바꿈 뒤에는 브라우저를 새로고침(F5) 해 주세요.
